# A practical is a different chain

[ADR 0009](0009-alignment-reaches-up-authoring-does-not.md) established that `make-exam` was wrong for practical examinations at five of its eleven steps, and rejected narrowing it *at that time* on one ground only: the replacement did not exist, and removing a capability before its successor lands leaves the work served by nothing. The successor exists now, so the narrowing happens.

The evidence was a real practical exam set. Against `make-exam`'s steps: research was the largest file in the folder where the skill calls it the step for what is left over; the blueprint was an alignment matrix of tasks reaching up to the programme outcomes, not a grid of topics by cognitive level; there was no item file at all, because the paper holds tasks with time budgets rather than items; the answer key was mostly a proctor manual; and the rubric carried a section on marker agreement that `make-exam` never mentions. A checklist whose order does not describe the work is not a checklist with exceptions — it is a different checklist wearing the same name, which is the case [ADR 0006](0006-how-a-skill-is-reached-and-when-it-is-split.md) reserved for a split.

**What replaces the written-exam machinery.** A practical has no distractors to audit and no key to defend, and the three things it has instead are exactly the three the written skill has no place for: **conditions** (equipment, time, permitted references, safety — the same task open-book measures something else), a **scoring instrument** chosen per task rather than one method throughout, and **markers**, whose disagreement is the default state and lands as marks. The pass standard is set before the examination for the same reason a blueprint is fixed before the items: a cut score decided after the marks are in is decided by the marks.

**The measured step comes across intact.** [ADR 0008](0008-a-check-that-leaves-no-evidence-did-not-run.md)'s rule is not specific to multiple-choice options. `make-practical` step 8 counts minutes per mark for every task, marks per outcome, the objective share against the judgement share, the number of independent tasks, and — where alternate forms exist — what happened when the author worked each of them under exam conditions. Two of the defects found in the real set were arithmetic that nobody had done: a task costing 2.2 times more minutes per mark than its neighbour, and four alternate briefs handed out at random that had never been compared.

## Considered Options

- **A branch inside `make-exam`** — rejected: five of eleven steps would carry "if practical, skip", which is not a branch but two checklists sharing a file, the arrangement [ADR 0006](0006-how-a-skill-is-reached-and-when-it-is-split.md) split `init-brain` to avoid.
- **Put practical defects in `make-practical`'s own reference** rather than in the `item-defects` skill, since only one skill consumes them and [ADR 0007](0007-shape-is-shared-process-is-copied.md) lets a first consumer keep a private default — rejected. `item-defects` declares itself one file per item format, and a practical is a format; a reader who looks there, does not find it, and writes their own copy is the exact drift the rule exists to prevent. Consistency of the home beat the one-consumer rule here.
- **A `scoring-instruments` reference skill** so `make-exam` and `make-practical` share rubric guidance — rejected as too small a thing to cost a permanently loaded description. The overlap is four bullets, which is copy-sized rather than share-sized, so it is copied and held identical by `_scripts/check.py`. That mechanism already existed for the discovery clause and had never been used for anything else.

## Consequences

- Thirteen skills where there were eleven. `make-practical` is model-invoked; `PRACTICAL-DEFECTS.md` joins the `item-defects` skill.
- `make-exam` is now a **written** exam skill: its description drops practical, its scope paragraph names where practical work went, its rubric step covers constructed-response only, and its reference loses the practical section. The commitment made in [ADR 0009](0009-alignment-reaches-up-authoring-does-not.md) is discharged.
- `_scripts/check.py` holds a fourth piece of text identical across files, and its identical-text rule now reads every markdown file in a skill folder rather than only each `SKILL.md` — the shared text this time lives in two sibling references, not in two step lists.
- The set's assessment side is now complete end to end: design the course, build a written exam or a practical from it, critique the written paper before use. The one gap left is a review pass for practical examinations, which nothing currently performs.
