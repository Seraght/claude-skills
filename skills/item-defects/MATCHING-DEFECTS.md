# Matching Defects

Defects that matching sets carry. The defects that apply to items of every kind are in [COMMON-DEFECTS.md](./COMMON-DEFECTS.md), and every set is judged against that file as well as this one.

A matching set is one item made of many marks, not many items. Its parts are not independent: a wrong pairing early forces a second wrong pairing later, so one lapse is scored twice — the defect [COMMON-DEFECTS.md](./COMMON-DEFECTS.md) calls a hinged item, built into the format itself. That is the cost the format is chosen in spite of, and it is why a set is kept short and its scoring stated.

**The host project governs.** Where a project or an institution fixes the form of a matching set, a set is not flawed for following it.

## Group A — pairings an unprepared examinee can still make

- **Mixed classes among the premises or the responses.** Where the list holds two kinds of thing — three diseases and two instruments — the examinee sorts by kind rather than by knowledge, and each correct sort removes several options. *Fix:* one homogeneous class per set; split the second class into its own set.
- **Equal counts with each response used once.** The last pairing is free, and the second-to-last is close to it. *Fix:* supply more responses than premises, or state that a response may be used more than once, or both.
- **Length and grammar cues.** One response is markedly longer, or only one agrees grammatically with a given premise. *Fix:* bring the responses to one length band and one grammatical form.
- **Word repeats between a premise and its response.** A shared term or root pairs them without any subject knowledge. *Fix:* replace the repeated word on one side, or use it across several responses.
- **One-to-one giveaways.** A response that can only belong to one premise on surface features — a date among names, a number among words — is matched without reading either. *Fix:* make every response plausible for more than one premise.

## Group B — irrelevant difficulty

- **The list is too long.** Search cost grows with the product of the two lists, and past a short set the item measures how fast an examinee scans. *Fix:* keep a set short and split a long one into two homogeneous sets.
- **Responses in no order.** An unordered response list forces a linear scan for every premise. *Fix:* order the responses — alphabetically, numerically, or chronologically — so the examinee can find rather than search.
- **The set breaks across a page.** Premises on one page and responses on the next turns the item into a memory task, and examinees miss responses entirely. *Fix:* keep the whole set on one page.
- **Instructions that do not say the rules.** Whether a response may be reused, and whether every response is used at all, changes the strategy completely. Left unstated, the examinee guesses, and the guess is worth marks. *Fix:* state both in the directions above the set.
- **Unstated scoring.** All-or-nothing scoring for a whole set and one mark per correct pairing produce very different scores from the same answers. *Fix:* state the scoring with the item, and prefer one mark per pairing so a single lapse does not take the whole set.

## Group C — congruence, level, and correctness

- **A premise with more than one defensible response.** Where two responses can both be argued for a premise, the set has no single correct arrangement, and the error propagates into every pairing that follows. *Fix:* tighten the premise, or remove the competing response.
- **Level ceiling.** Matching tests recognition of an association. An Apply, Analyze, or Evaluate cell cannot be filled by a matching set, whatever the verb in the directions says. *Fix:* use the format for the Remember and Understand cells it serves well, and fill higher cells with a format that can reach them — which is a blueprint decision, made before the set is written.
- **Filler responses.** Extra responses added only to break the one-to-one count, that no examinee would ever choose, do no work and are visible as padding. *Fix:* every extra response names a real confusion — an association an examinee actually makes.

## Group D — the paper as a whole

- **Marks concentrated in one set.** A set of eight pairings scored one mark each spends eight marks on one topic at one cognitive level. Reconcile that against the blueprint, not against the item count.
- **A response list that overlaps another set's** invites carry-over between sets, and an examinee who reads both gains information neither was meant to give.
